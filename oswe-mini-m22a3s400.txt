Summary of issues found and fixes
1) truncateText — edge-case bug
- Problem: truncateText used maxLength - 3 without guarding small maxLength. For very small maxLength (<= 3) substring indices became invalid and behavior was wrong.
- Fix: Handle small maxLength explicitly and avoid negative substring indices. For small max lengths return the substring and append '...' only when trimmed. (src/utils/helpers.ts)
- Tests: Added tests to assert empty inputs, equality cases, and small-maxLength ellipsis behavior (src/utils/helpers.test.ts).

Corrected code (excerpt)
export const truncateText = (text: string, maxLength: number): string => {
  if (!text || maxLength <= 0) return ''
  if (text.length <= maxLength) return text
  if (maxLength <= 3) {
    // For very small max lengths, don't attempt to reserve space for ellipsis
    return text.substring(0, maxLength) + (text.length > maxLength ? '...' : '')
  }
  return text.substring(0, maxLength - 3) + '...'
}

2) debouncedSearch — API/behavior problem
- Problem: Exported value was a pre-debounced function with an ignored delay parameter, making it impossible to use custom delays; it also offered no way to cancel or get the returned debounced function.
- Fix: Change to a function factory that returns a debounced wrapper using the provided delay so callers control the delay and can cancel when needed (src/utils/helpers.ts).
- Tests: Added tests that use fake timers to assert the debounced callback is invoked only after the specified delay (src/utils/helpers.test.ts).

Corrected code (excerpt)
export const debouncedSearch = (callback: () => void, delay: number = 300) => {
  // Return a debounced wrapper that can be cancelled by the caller if needed
  return debounce(callback, delay)
}

3) groupBy — falsy key bug
- Problem: groupBy used item[key] || 'undefined' which maps falsy but valid keys (0, '') to 'undefined' bucket.
- Fix: Use nullish coalescing (item[key] ?? 'undefined') so falsy valid keys are preserved (src/utils/helpers.ts).
- Tests: Added tests to ensure 0 and empty string keys are grouped correctly (src/utils/groupBy.test.ts).

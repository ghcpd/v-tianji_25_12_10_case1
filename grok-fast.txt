## Summary of Function-Level Bugs Analysis and Fixes

### Bugs Identified and Fixed

1. **Regex Injection Vulnerability in Search Component**  
   - **Location**: Search.tsx - `highlightText` function  
   - **Issue**: The function created a RegExp directly from user input without escaping special characters, potentially causing invalid regex or unexpected behavior if the search query contained characters like `(`, `)`, `[`, etc.  
   - **Fix**: Added an `escapeRegex` utility function to helpers.ts and modified `highlightText` to escape the highlight string before creating the RegExp.  
   - **Code Change**: 
     ```typescript
     // Added to helpers.ts
     export const escapeRegex = (string: string): string => {
       return string.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')
     }

     // Modified in Search.tsx
     const escaped = escapeRegex(highlight)
     const parts = text.split(new RegExp(`(${escaped})`, 'gi'))
     ```

2. **TypeScript Type Errors for Timer References**  
   - **Location**: Dashboard.tsx and Search.tsx  
   - **Issue**: Used `NodeJS.Timeout` type for `setTimeout` references, which is Node.js specific and not available in browser environments.  
   - **Fix**: Changed type to `number` as `setTimeout` returns a number in browsers.  
   - **Code Change**: 
     ```typescript
     const intervalRef = useRef<number | null>(null)
     const debounceTimer = useRef<number | null>(null)
     ```

3. **Unused Code in Helpers**  
   - **Location**: helpers.ts  
   - **Issue**: Imported `debounce` from lodash and defined `debouncedSearch` function that was never used, and had an unused parameter causing TypeScript warnings.  
   - **Fix**: Removed the unused import and function.
